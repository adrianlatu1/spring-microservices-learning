# Spring Microservices Learning Path

Reluare sistematică: Java 8 → Spring Boot → Docker → Microservices → Cloud.

## Obiectiv
Să mă readuc aminte de concepte și să construiesc aplicații funcționale, de la local la cloud.

## Plan — 3 săptămâni inițiale

### Săptămâna 1: Java 8 + Spring Boot Basics
- **Java 8 recap:** lambde, streams, funcții de ordin superior
- **Spring Boot:** REST API, bază de date, validare, teste
- **Timp alocat:** ~10-12 ore
- **Output:** O aplicație simplă, funcțională, pe care o înțeleg de cap la coadă

📁 `/week-1-basics/`

### Săptămâna 2: Docker + Microservicii
- **Docker:** containerizare, docker-compose, rulare locală
- **Comunicare:** HTTP între servicii, introducere la mesagerie (RabbitMQ/Kafka lite)
- **Debugging & Logare:** cum urmăresc ce se întâmplă între servicii
- **Timp alocat:** ~10-12 ore
- **Output:** Doi-trei servicii care vorbesc între ei, containerizați

📁 `/week-2-docker-microservices/`

### Săptămâna 3: Observabilitate + Cloud
- **Metrici și logare centralizată** (ELK stack sau similar)
- **CI/CD:** GitHub Actions, deploy automat
- **Cloud:** alegem furnizor (AWS Free Tier), deploy primul serviciu
- **Timp alocat:** ~10-12 ore
- **Output:** Servicii pe cloud, monitorizate, cu pipeline de deploy

📁 `/week-3-observability/`
